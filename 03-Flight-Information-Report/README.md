# Flight Information Report

## 📌 Project Overview

This is a SAP ABAP learning project developed as a Flight Information / Flight Reservation Report.

The report retrieves flight-related information based on user-provided selection criteria and presents the selected flight details in a structured report format.

This project was developed as part of my SAP ABAP learning journey and helped me practice selection screens, database retrieval, internal table processing, calculations, and classical report output.

## 🔎 Selection Criteria

The report provides selection options for flight-related information, including:

- Carrier
- Departure City
- Arrival City
- Flight Date

The selected criteria are used to retrieve the relevant flight records.

## ✈️ Flight Information

The report displays information such as:

- Airline / Carrier
- Connection ID
- Departure City
- Arrival City
- Flight Date
- Maximum Seats
- Occupied Seats
- Available Seats
- Occupancy Percentage
- Flight Status

## 🧮 Flight Availability Calculation

The report processes the flight capacity information and determines the number of available seats.

It also calculates the occupancy percentage based on the available flight data.

## 📋 Report Output

The report first displays a flight reservation summary containing the selected flight information.

The user can then view detailed information for a selected flight.

The detailed output includes flight information and availability status.
